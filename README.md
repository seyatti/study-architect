# Study Architect

## 概要

Study Architectは、学習記録の管理とデータ分析を通じて、学習の継続を支援するPython製のWebアプリケーションです。

日別・科目別・曜日別の学習時間や学習傾向を可視化し、自分の学習状況を多角的に振り返ることができます。また、学習目標の設定と進捗確認にも対応しています。

## 開発背景

学習を継続するうえで、自分の努力や積み重ねが目に見えることは、モチベーションを維持するための重要な要素だと考えています。

しかし、既存の学習管理アプリでは、自分が求めるような多角的な分析ができるものが少ないと感じていました。

そこで、単に学習時間を記録・保存するだけでなく、蓄積したデータから学習傾向や取り組みの変化を把握できるアプリを開発しました。

学習状況を客観的に振り返ることで、達成感を得られるだけでなく、今後の学習計画を考えるきっかけを提供することを目指しています。

## 今後の展望

将来的にはAIを活用した学習支援機能の導入を予定しています。

学習履歴に基づく傾向分析や、次に取り組む学習内容の提案などを実装し、学習者が「次に何を勉強すべきか」と悩んだときにも役立つアプリへの発展を目指します。

## 主な機能

Study Architectでは、学習記録の管理からデータ分析、学習目標の設定まで、一連の学習管理を行うことができます。

### 1. 学習記録の管理
- 学習日・科目・学習時間を記録
- 登録済みの学習記録の編集・削除
- SQLiteによる学習データの保存

### 2. 学習状況の可視化
- 総学習時間・1日あたりの平均学習時間の表示
- 過去の期間との学習時間の比較
- 科目別の学習時間を棒グラフで表示
- 日別の学習時間の推移を折れ線グラフで表示
- ヒートマップによる過去約1年間の学習活動の可視化
- 連続学習日数や最も学習した科目の表示

表示期間は「1週間・1か月・1年・全期間」から切り替えられます。

### 3. 詳細な学習データ分析
- 1日の学習時間の平均値・中央値・標準偏差
- 曜日別の平均学習時間と学習実施率
- 直近7日間の学習傾向
- 科目別の学習統計・学習傾向の比較
- 週ごとの学習日数の推移

単純な学習時間の合計だけでなく、学習習慣や学習時間のばらつきを把握できます。

### 4. 学習目標の管理
- 目標学習時間と対象期間の設定
- 目標達成率の表示
- 目標達成までの残り時間・残り日数の確認
- 目標達成に必要な1日あたりの学習時間の算出

### 5. 入力設定のカスタマイズ
- 学習時間の入力単位を「分・時間」から選択
- 学習時間の入力間隔を変更
- 設定内容の保存
